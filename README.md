# دعوة زفاف أحمد ومريم

صفحة دعوة زفاف تفاعلية باللغة العربية، مبنية باستخدام Next.js وReact.

## المتطلبات

- Node.js 20 أو أحدث
- npm

## التشغيل محليًا

```bash
npm ci
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000) لمشاهدة الدعوة.

## إنشاء نسخة الإنتاج

```bash
npm run build
npm start
```

## محتويات المشروع

- `app/` إعدادات ومسارات Next.js
- `assets/` صور الدعوة
- `invitation.tsx` مكوّن الدعوة التفاعلية
- `invitation.module.css` تنسيقات الدعوة
